# Included code and assets

Gallery code is Apache-2.0 licensed; see [LICENSE](LICENSE).

Phoenix is a Git submodule at [external/phoenix](external/phoenix), from
https://github.com/RazvanManolache/dlss5-phoenix-addon. Its implementation, kernel
sources, dependency headers and licenses live in that repository. No Phoenix
implementation files are copied into the gallery repository.

NGX SDK headers and compatible neural weights are supplied separately by the
user. No NVIDIA model DLL or neural weights are distributed in this repository.

Scene model/texture/animation attribution is in [CREDITS.md](CREDITS.md) and
[licenses](licenses/). Large scene files are delivered as a separate verified
asset pack; its own attribution files are installed alongside the scene assets.
